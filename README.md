# CLI for AniList

CLI for AniList is a Rust command line interface for the [Manga/Anime](https://anilist.co) tracker.

## Development

### Prerequisites
- cargo
- rust

Install from the [Rust website](https://rust-lang.org/learn/get-started/)

### 1. Clone project
```
git clone https://github.com/aikenahac/anilist-cli.git
```

### 2. Run the project
```
cargo run
```
